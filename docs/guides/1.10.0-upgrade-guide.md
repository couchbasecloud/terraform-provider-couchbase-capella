# Couchbase Capella Provider 1.10.0: Upgrade and Information Guide

Here is a list of what's new in 1.10.0

## New Features

* Support for Eventing Service
* Support for CIDR block in App Services
* Data API configuration support

## Enhancements

* Automated Private Endpoint Acceptance

## Bug Fixes

* Fixes a crash in the couchbase-capella_private_endpoints data source: reading it against a cluster that has one or more private endpoints failed with a Value Conversion Error
* Retry once before treating enableFailed/disableFailed as terminal
* when creating an eventing function with large payload, tf reports error `Provider produced inconsistent result after apply`
* Disable audit log settings
* Allow App Service to be deployed with a specific version

## Changes

1.10.0 includes new features and general improvements. See the [CHANGELOG](https://github.com/couchbasecloud/terraform-provider-couchbase-capella/blob/master/CHANGELOG.md) for more specific information.
