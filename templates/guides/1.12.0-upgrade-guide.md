# Couchbase Capella Provider 1.12.0: Upgrade and Information Guide

Here is a list of what's new in 1.12.0

## New Features

* Support for fine-grained RBAC.
## Enhancements

* Support for downloading bucket backups

## Bug Fixes

* Fix to set OIDC fields to null when left in an unknown state after a failed refresh
* Fix for App Services OIDC Create
* Fix for Azure disk auto-expansion default when unset
* Allow empty list for eventing function bindings

## Changes

1.12.0 includes new features and general improvements. See the [CHANGELOG](https://github.com/couchbasecloud/terraform-provider-couchbase-capella/blob/master/CHANGELOG.md) for more specific information.
