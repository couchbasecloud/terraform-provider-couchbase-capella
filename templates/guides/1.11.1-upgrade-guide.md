# Couchbase Capella Provider 1.11.1: Upgrade and Information Guide

## Bug Fixes

* Applying `couchbase-capella_app_service_onoff_ondemand` with the activation state the app service is *already* in failed the apply
* Reverting a breaking change for AV-139841

## Changes

There are no deprecations as part of this release.

1.11.1 also includes general improvements and bug fixes. See the [CHANGELOG](https://github.com/couchbasecloud/terraform-provider-couchbase-capella/blob/master/CHANGELOG.md) for more specific information.
